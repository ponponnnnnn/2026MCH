# 規則示範對話（非盲測，手寫示範用來檢查規則是否合理）

> 這份跟 `blind-persona-test-2026-09-19.md` 不同：這裡是我自己寫的示範對話，用來對照 O1-O8/R1-R15 規則是不是套得通，不是真的盲測。盲測結果請看同資料夾的 blind-persona-test 檔案。

---

## 示範一：例行通話（非首次），展示話題轉換 R 系列 + 紅旗中斷

場景：晚上 7 點，AI 主動打給獨居的陳奶奶，已經聊過幾次。

AI：「喂？陳奶奶你在嗎？」
（沉默 2 秒）
AI：「陳奶奶？」
陳奶奶：「喔喔，在在，你等我一下喔。」
*[O1 呼喚-應答，第二次才有回應，繼續往下走]*

AI：「奶奶，是我啦，你的陪伴小幫手。」
*[O2 身分互認，單獨一輪，沒黏話題]*

AI：「吃飽了嗎？」
*[O3 問候詞，仍不是實質問句]*

陳奶奶：「吃飽啦。」

AI：「奶奶你今天過得怎麼樣啊？」
*[O4 開放式近況問句，不是直接問健康清單；O8 例行通話走精簡版]*

陳奶奶：「還不就那樣啊，跟平常一樣。」
*[制式簡短回應 → O5 分流：轉去 O6 安全話題清單]*

AI：「對了奶奶，上次你不是說要種的那個九層塔，發芽了沒？」
*[O6：從 topic_hooks 記憶庫抓「上次提過的種植」當安全開場話題]*

陳奶奶：「有喔，發了兩三根了，我每天都有去看它。」
*[展開型回應]*

AI：「哇那你每天都要去外面看喔？」
*[R1 EXPAND，追問同一個社交話題延伸]*

陳奶奶：「對啊，就走出去陽台看一下，順便曬曬太陽。」
*[這句其實命中了「戶外活動/曬太陽」的 NIA 提醒層 → 悄悄記錄，長輩完全不知情]*

AI：「這樣很好耶，曬太陽對身體好。對了奶奶，你這句話讓我想到，最近睡得還習慣嗎？」
*[R9/R10 錨點橋接：用「曬太陽/身體好」當樞紐句，接到下一個清單項目「睡眠」]*

陳奶奶：「唉呦，最近比較難睡，半夜都會醒來看時間。」
*[展開型回應 → R1 EXPAND，可以再追問一次]*

AI：「喔～是喔，那你醒來會不會很難再睡著？」
*[背景：log_health(sleep, "半夜易醒", "半夜都會醒來看時間")]*

陳奶奶：「還好啦，滑一下手機就睡著了。」

AI：「這樣啊，滑手機。」
*[R3 強制反映句，不再追問，槽位標記 COLLECTED，回到 IDLE]*

……（幾輪之後）……

陳奶奶：「對了，我跟你說，我今天差一點跌倒，頭很暈。」

AI：「奶奶你現在人在哪裡？有沒有受傷？」
*[R4 紅旗詞覆蓋一切，中斷本狀態機，直接進 raise_alert 流程；背景：raise_alert(red) → 10秒內家屬 Gmail 收到緊急通報]*

陳奶奶：「我坐在椅子上啦，沒有跌倒，就頭暈一下下。」

AI：「奶奶你先坐著不要亂動喔，我已經跟你家人說一聲了，他們會盡快聯絡你，你先休息一下好不好？」

……

AI：「奶奶今天聊得很開心，記得晚上的藥要按時吃喔，我們明天再聊。」
*[§8 固定收尾]*

**掛掉之後背景動作**：睡眠、曬太陽兩筆悄悄寫進資料庫；頭暈那筆已經是紅色 alert，通話當下就通報完了不用等晚上；「發芽的九層塔」存成新的話題掛勾，明天才有新梗接話；晚上 8 點排程把今天全部資料丟給 Gemini 產生晚報。

## 示範二：首次通話冷啟動 + 長輩主動觸情緒深話題 + 一個系統接不住的狀況

場景：第一次通話，長輩剛裝好 App，AI 完全沒有任何 topic_hooks 可用。

AI：「喂？王爺爺您在嗎？」
（無回應）
AI：「王爺爺？」
王爺爺：「啊？誰？」
*[O1 呼喚-應答，第二次才有回應]*

AI：「爺爺您好，我是您子女幫您裝的陪伴小幫手，以後會常常打給您聊聊天。」
*[O2 身分互認 + O7 首次通話先講目的，跟閒聊分開]*

王爺爺：「喔…好。」

AI：「那我們大概固定晚上這個時間打給您方便嗎？」
*[O7 事務性確認]*

王爺爺：「方便，都可以。」

AI：「好，那爺爺，您最近過得怎麼樣啊？」
*[O4 開放式近況問句]*

王爺爺：「就這樣啊，沒什麼。」
*[制式簡短 → O5 沒升格 → 轉 O6，但首次通話沒有任何話題掛勾，O6 清單是空的]*

AI：「爺爺平常在家都做些什麼打發時間呀？」
*[零錨點、零掛勾 → R14 fallback，鎖 Tier1，用 FORM 的 Recreation 起手]*

王爺爺：「就看看電視啊，能幹嘛。」
*[敷衍 → R1 CLOSED]*

AI：「電視喔。」
*[R3 強制反映句，不追問]*

AI：「爺爺您平常有種花種菜還是養什麼寵物嗎？」
*[R14 換下一個 Tier1 類別]*

王爺爺：「以前有跟我老伴一起種一些菜啦……她走了以後我就沒再弄了。」
*[意外展開，長輩自己主動開了 Tier3 情感脆弱的門]*

AI：「喔…爺爺，聽您這樣說，會不會捨不得？」
*[2.1 機制：同錨點往下追問，因為是長輩自己開門，AI 才跟進 Tier3，不是主動起手]*

王爺爺：「當然捨不得，一個人吃飯都覺得沒意思，晚上也睡不好。」
*[展開，同時命中「睡眠」槽位；背景 log_health(sleep,"睡不好",原話)。心情偏低有記錄但單次提及不到黃色警報門檻，先觀察不驚動]*

AI：「這樣啊，一個人吃飯真的會覺得比較冷清。」
*[R3 反映句，情緒類收快一點，不深挖]*

王爺爺：「對了，前幾天還有人打電話來說要幫我保單解約，退我十幾萬，我聽了覺得怪怪的沒理他。」
*[⚠️ 這句話系統完全沒對應規則——健康清單、ICOPE、NIA/AGS、R4紅旗詞都沒有「詐騙」這個維度]*

AI：「這樣子啊，那還好您有多留意。」
*[只能泛用回應接住，沒觸發 log_health 也沒觸發 raise_alert，這件事完全沒被記下來]*

AI：「爺爺今天謝謝您跟我聊這麼多，明天再打給您喔。」
*[首次通話收尾，語氣輕，還沒建立信任前不直接叮嚀用藥]*

**驗收結果**：
- O1/O2/O7 順序對，目的說明沒跟閒聊混一句 ✓
- 零掛勾冷啟動走 R14 且鎖住 Tier1 ✓（這正是後續研究要鎖 Tier1 的原因）
- 長輩自己開 Tier3 的門，AI 同錨點跟進、沒有硬翻新話題，順便悄悄記到 sleep ✓
- 情緒偏低沒有過度追問 ✓
- **詐騙電話那句直接漏接** ✗ —— 這是「獨居長輩擔憂主題」研究點名的缺口，這裡示範跑出來：長輩主動講了疑似詐騙未遂，系統毫無反應，家屬晚報也看不到。這個缺口後來在 `blind-persona-test-2026-09-19.md` 的真實盲測裡再次被驗證存在（詐騙電話設定為隱藏測試事件）。
